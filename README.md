# Minimal New Tab

A tiny, distraction-free new tab page inspired by minimal productivity dashboards and NASA-themed browser starts.

## Features

- Clean dark interface
- Live time and date
- Search box with multiple search engines
- Quick links for your favorite sites
- NASA Picture of the Day card
- Lightweight and dependency-free

## Run locally

From this folder, start a local web server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Notes

This project is intentionally minimal and is designed to be easy to customize. The quick links are stored in localStorage so they can be edited later without a backend.
